# Managing Referrals

FluentAffiliate displays your referrals in a single dashboard, it's an easy to use dashboard packed with tools to manage and track affiliate referrals. In this guide, we'll walk you through how referrals work and the features available to help you stay in control.

### Referral Dashboard

The Referral Dashboard in FluentAffiliate gives you all the tools you need to manage and track referral activity efficiently. Here's what each option does:

**a. Filter**: Easily filter referrals by status — Unpaid, Paid, Pending, or Rejected.

**b. Search**: Quickly find specific referrals by entering keywords or details.

**c. Column Selection**: Choose which columns you want to display in the referral table.

**d. Sort**: Sort your referrals by Amount, ID, or Reference in ascending or descending order. Don't forget to hit **Apply** after sorting.

**e. ID**: Unique ID for each referral. Click it to view detailed information.

**f. Affiliate**: The username of the affiliate who generated the referral. If you click on this username, you will see the Profile of this affiliate with all the details.

**g. Amount**: Displays how much commission the affiliate earned for each referral.

**h. Description**: Shows details about the product or service associated with the referral.

**i. Reference**: The source or reference linked to the referral.

**j. Status**: Indicates if the referral is **Paid**, **Pending**, or **Unpaid**.

**k. Type**: Shows the source type that generated the commission.

**l. Date**: Displays the date the referral was created.

**m. Action Menu (Three Dots)**: Click here to **Edit** or **Delete** the referral.

**n. Pagination**: Choose how many referrals to display per page.

**o. Page Navigation**: Use the arrows to move between pages.
