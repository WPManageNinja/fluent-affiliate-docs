# Affiliate Profile

FluentAffiliate creates a dedicated profile for each affiliate, allowing you to view and manage their referrals, visits, and payouts in one place. In this article, we’ll show you how to access an affiliate’s profile and track their activity effortlessly.

## Access Affiliate Profile

To access an affiliate’s profile, go to the **Affiliates** section from the FluentAffiliate top menu. You’ll see a list of all your affiliates. Click on the **Name** of the affiliate whose activity you want to view or manage.

## Overview

Once you’re redirected to the affiliate’s profile page, you’ll find detailed information about that affiliate.

In the **Overview** section, you can view key stats such as:
* Total Earnings
* Paid Earnings
* Unpaid Earnings
* Referrals
* Total Visits

The **Statistics** section includes a bar chart displaying referral and visit data for better visual insight. You can use the date range filter to view affiliate data for a specific time period.

You’ll also see an **Affiliate Details** section showing the affiliate’s profile information. To edit any of these details, simply click the **edit icon** within this section.

In the Affiliate Edit section, you can update the Rate Type, Status, Payment Email, and add a Note for the affiliate. Once you’re done, click the **Submit** button to save your changes.

## Referrals

In the **Referrals** section, you can view all referral details for the affiliate. To make any changes, click the three-dot menu next to a referral and select the **Edit** option.

## Visits

In the **Visits** section, you can track all visits made through the affiliate’s referral links. You’ll also see which links have converted into referrals and which haven’t.

## Transactions

In the **Transactions** section, you can view all transactions related to the affiliate. To manage a transaction, click the three-dot menu next to it you’ll see two options: **Edit** and **Delete**.

Choose **Edit** to update any transaction details, or click **Delete** to remove the transaction.

That’s how you can manage everything from the affiliate profile. If you have any questions about using the affiliate profile, feel free to reach out to our **support team**.
